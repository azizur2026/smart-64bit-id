# SMART 64-Bit ID v1.41 — Changelog

## v1.41 — Stable

- Declares the v1.41 specification stable.
- Establishes the normative 64-bit field layout and profile selection rules.
- Defines Engine + Local as the authoritative uniqueness coordinate.
- Clarifies Class, Role, reserved-bit validation, and Engine-based routing.
- Documents migration behavior and the boundary between v1.41 and legacy v1.4.
- Keeps global Engine governance and future routing/sharding proposals deferred.

The normative requirements for this release are defined in [`SPECIFICATION.md`](SPECIFICATION.md). If this changelog or any explanatory document conflicts with the specification, the specification takes precedence.
